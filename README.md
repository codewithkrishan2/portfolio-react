# Portfolio — Krishan Kant Singh Gautam

Live at **[codewithkrishan.netlify.app](https://codewithkrishan.netlify.app)**

Statically generated portfolio site. Next.js 16 App Router, exported to plain
HTML so every page ships crawler-visible content.

## Stack

| | |
|---|---|
| Framework | Next.js 16.4.2 (App Router, Turbopack) |
| UI | React 19.3.1, TypeScript |
| Styling | Tailwind CSS v4 with CSS-variable theme tokens |
| Animation | `motion` 14 |
| Theming | `next-themes` (dark default, light available) |
| Contact form | EmailJS |
| Images | Pre-optimised at build time with `sharp` |
| Hosting | Netlify (static `out/` directory) |

## Commands

```bash
npm install
npm run dev               # dev server on :3000
npm run build             # static export to out/
npm run lint              # eslint
npm run optimize:images   # re-generate public/img from assets/originals
npm run shots             # build first, then capture screenshots at 3 widths
```

## Layout

```
app/              routes, metadata, robots.ts, sitemap.ts
components/       section and UI components
lib/site.ts       contact details, URLs, analytics IDs
lib/data.ts       all page copy: services, experience, projects, skills
public/img/       optimised, shipped assets
assets/originals/ full-resolution sources (not deployed)
scripts/          image pipeline, OG image, screenshot capture
```

Content changes generally mean editing `lib/data.ts` only.

## SEO notes

The previous version was a client-rendered Vite SPA: the served HTML was an
empty `<div id="root">`, so link-preview scrapers (LinkedIn, WhatsApp, Slack,
X) saw a blank page. This version fixes that and the related issues:

- static export — real HTML in the response
- Metadata API: description, canonical, Open Graph, Twitter card
- JSON-LD `Person` structured data
- `robots.txt` and `sitemap.xml` generated at build
- one `<h1>` per page, headings descending without skips
- `<main>` / `<header>` / `<nav>` / `<footer>` landmarks
- labelled form inputs, named icon buttons, visible focus rings
- `og-image.png` (1200×630) generated by `scripts/make-og-image.mjs`

## Environment

Copy `.env.example` to `.env.local`. The EmailJS values are browser-side by
design; the code falls back to working defaults if they are unset.

## Images

`public/` ships only optimised WebP. Originals live in `assets/originals/` and
are not deployed. To change an image, replace the original and re-run
`npm run optimize:images`.

The project card images are stock placeholders — none of these projects is
currently deployed. Replace them with real screenshots as the projects go live.
